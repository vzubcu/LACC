# Review-driven v2.4 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans task by task.

**Goal:** Fix confirmed helper defects and reduce routine memory maintenance overhead.
**Architecture:** Existing portable scripts, explicit safe mutations, optional benchmarking within the memory skill.
**Tech Stack:** Bash, Python 3.9+, Git, optional ripgrep, stdlib unittest.
**Spec:** docs/superpowers/specs/2026-11-02-review-v24-design.md

## Global Constraints

- No daemon, embeddings, provider SDK or automatic semantic deletion.
- New instruction paths preserve existing user content and reject symlinks.
- Output byte limits are not token-saving measurements.
- Publish a PR; user approval of earlier PR merges is not a merge instruction for this change.

## Review Focus

- Generic source directory names must not hide consumers.
- Preview/apply races and dirty Git sources must never advance evidence silently.
- UTF-8 and long single lines must respect output limits without corrupting records.
- Bootstrap fingerprints must not hide subsequent user edits.
- Every installed skill must work without files from its sibling or the repo root.
